Mobile Responsiveness Test

This page is designed to adapt to your screen size. If you are on a desktop, try resizing your browser window or use the Browser Responsive Mode (F12) to see the changes!

When the screen width drops below 600px:

  • The background color will turn light blue.
  • The font size will decrease for better readability.
  • The horizontal menu will stack vertically.
